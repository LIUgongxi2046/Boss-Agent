# Boss Agent × 大鹏 · 电脑端完整长页面设计 v7.0

## 交付范围

本包基于已经确认的 Boss Agent Logo、蓝绿白配色、大鹏吉祥物和 v6.0 桌面设计继续优化，不改变核心视觉风格。覆盖最初 `Boss-Agent-page-prompts.zip` 中的 **72 个电脑端主视图**（F01—F32、N01—N12、A01—A16、D01—D09、V19-BEEF / EGG / MILK）。

- `images/`：72 张逐页独立的高清 PNG，宽 **2880px**，高度按页面完整内容自适应，不再统一裁切为 2048px。此次有 **52 张**超过原始单屏高度，最长为 N02 **2880×5256px**。
- `images-1x/`：与高清 PNG 一一对应的 1× PNG，宽 1440px，高度按比例缩小。
- `pages/`：72 份可单独打开的 HTML 页面，完整保留视觉、输入控件、设计交互和响应式规则。打开时可在页面内切换为“完整长页面”，或使用 `?long=1` 直接进入长页面视图。
- `index.html`：可检索的 72 页设计图库。**优先从这个文件打开**，可查看页面、高清图和原始编号。
- `previews/`：核心 16 页、全部 72 页总览及 6 张分组详览。
- `assets/`、`animation/`：原版 Boss Agent Logo、大鹏统一形象与上一版场景动效资产。
- `design-v7.css`、`design-v7-panels.js`、`design-v7-runtime.js`：v7 的页面深化、长页面及预览交互源码，建立在 v6 的组件与设计 Token 基础上。
- `page-index.csv`、`page-index.json`：页面 ID、分组、图像尺寸、主视图和源提示词映射。
- `design-state-index.csv`、`source-prompts/`：原始 **561 条桌面状态提示词**与源文件索引。这里的状态索引 **不等于 561 张状态图**，本轮只完成 72 个主视图的全长高清出图。
- `qa/`：渲染高度、资源加载、脚本错误和横向溢出检查结果。

## 本轮主要修订

1. **完整长页面输出**：修复原版固定高度与内部滚动导致的导出截断，扩展所有主要内容区；页面本身短时仍按正常单屏输出，不刻意拉长。
2. **N02 聊天交办重点深化**：连续对话、上下文与会话列表、任务步骤、补条件、来源与授权、异常恢复、附件与产物、经营指标占位、跨页面关联入口，全部在一张连续长图中可见。示例对话注明 DEMO，不是海大集团真实业务或实际模型执行结果。
3. **F05 纪要核查**：意见 / 建议 / 明确决定 / 交办草稿的分类编辑、逐项创建与发送、来源版本变更和历史结果查询。
4. **F06 交办详情**：本人确认前的结果提交、证据完整性、延期审批、取消影响、消息与催办记录分别表达。
5. **F27 语音交办**：许可、录音、上传、转写、文本核查、提交、失败和取消的完整阶段；未确认文字不触发业务动作。
6. **F01、N05、A08、A09、A13**：强化事项排序、任务状态、模型真实验证、工具版本与连接、调度去重和恢复的设计信息。
7. **跨窗口审阅**：基准 1440×1024；对关键页面做 1280×800、1024×768 及相当于缩小有效工作区的重排检查。

## 与真实软件的边界

所有页面都是可审阅的**高保真设计稿**，部分按钮提供本地模拟交互，不代表真实 API、用户授权、操作系统权限、消息发送、任务执行和数据库写入已实现。无实际业务资料时使用“待查询、待核查、未调用、未知”等表达；所有演示示例与真实生产数据严格区分。

原压缩包的状态提示词已完整保留并建立索引，但 **561 条状态没有逐条生成独立 PNG**。桌面安装、接口绑定和真实系统行为依然需要在开发交付与测试中验证。
