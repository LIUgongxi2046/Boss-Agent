## 宿主条件

本机 `uname -m` 为 `x86_64`；`sw_vers` 为 macOS 13.7.8，构建号 22H730。`df -h .` 显示数据卷可用约 8.7 GiB。U2-03 既有本机查询记录为 4 个逻辑处理器和 8 GiB 内存；本次环境拒绝内存及处理器数量查询，须在安装前重新核查可用资源。既有虚拟化能力查询仅证明当时支持查询，安装前还须重新验证硬件能力、签名权限及虚拟机配置。不得清理用户文件。

## 可供审查的环境对象

- Apple `Virtualization.framework`，Intel 宿主使用 Debian amd64，安装启动采用 `VZEFIBootLoader`、独立 EFI variable store 和专用虚拟磁盘。Apple 文档说明该框架支持 Intel Mac 上的 Linux，ISO 安装使用 EFI 启动器：[Linux 虚拟化](https://developer.apple.com/documentation/virtualization/virtualize-linux-on-a-mac)、[启动器](https://developer.apple.com/documentation/virtualization/vzbootloader?changes=la_5&language=objc)。当前系统上的 EFI 安装及权限尚未验证。
- 固定候选 `debian-13.7.0-amd64-netinst.iso`；Debian [官方发布信息](https://www.debian.org/releases/)及[安装目录说明](https://www.debian.org/CD/http-ftp/)列出 13.7.0 为当前稳定安装映像。固定版本目录为 `https://cloudfront.debian.net/cdimage/release/13.7.0/amd64/iso-cd/`。Debian [说明](https://www.debian.org/CD/netinst/) netinst 包含安装器和基础软件，其他所选软件需要另外获取。
- U2-03 的待测配置为 2 个虚拟 CPU、2 GiB 内存、6 GiB 系统磁盘和独立 2 GiB 运行工作区，技术检查建议宿主预留 12 GiB 可用空间；该建议尚未证明足够容纳固定 Hermes 和全部依赖。虚拟磁盘的逻辑容量与宿主实际占用不同，稀疏文件的实际占用随写入增长；空间预算须另计约 756 MiB 映像、软件包与缓存、工作区、日志和快照，并留出安全余量。当前约 8.7 GiB 可用空间不足以满足已记录的 12 GiB 技术检查建议，尚不能证明可执行。Debian [安装指南](https://www.debian.org/releases/trixie/amd64/ch03s04.en.html)给出的无桌面建议为 1 GB 内存和 4 GB 磁盘，不包含本项目依赖、证据与数据。

## 摘要和签名

Debian [验证说明](https://www.debian.org/CD/verify)要求验证同目录签名文件，再检查映像摘要；其中 Debian CD signing key 指纹包括 `DF9B 9C49 EAA9 2984 3258 9D76 DA87 E80D 6294 BE9B` 和 `1046 0DAD 7616 5AD8 1FBC 0CE9 9880 21A9 64E6 EA7D`。实际签名者必须从对应签名中读取，并与官方公布的完整指纹核对；不能预设其中哪一把签发了本映像。公钥和校验文件应来自 Debian 公布的密钥及对应版本目录，使用独立 keyring，通过 `gpgv --keyring <已核验公钥文件> SHA256SUMS.sign SHA256SUMS` 验证签名，再用 `shasum -a 256 <映像文件>` 与已验证清单中的同名条目比较。记录文件、签名者完整指纹、命令和输出摘要。

本次从 Debian 13.7.0 固定版本目录取得 `SHA256SUMS` 和 `SHA256SUMS.sign`，从 Debian 验证页面取得两把官方 CD 签名公钥，保存在项目内已忽略的 `.work/upgrade2/iso-signature-check/`。清单中的 `debian-13.7.0-amd64-netinst.iso` SHA-256 为 `a7ef94ac2fb9a7fec454552abd629b7cc9d5155c886165a45649f5ce6167e355`。本机未发现 `gpg`、`gpgv` 或 `sq`，因此尚未核验签名或实际签名者，该摘要当前仅为已取得的清单内容。未下载映像，映像摘要也未执行比较；两项验证通过之前不得使用映像。

网页检索对 `cdimage.debian.org` 返回 robots.txt 限制；该域名未通过其他方式访问。`ftp.us.debian.org` 的 HTTPS 连接出现证书名称不匹配，未关闭证书验证。上述两个地址未用于获取材料。

## 内核、系统文件与依赖

EFI 安装后从安装结果记录 `uname -r`、已安装 `linux-image` 包的精确版本、包摘要、完整软件包清单及 EFI 磁盘摘要。Debian 13 的发布说明列出 Linux 6.12 系列，具体构建版本取决于安装时的软件源，不能由 netinst 文件名单推断。使用[Debian snapshot](https://snapshot.debian.org/)固定经核验的仓库时间、Release 签名和各包版本；快照时间、实际可用包以及安全更新组合须在实施前确认。若后续选择 `VZLinuxBootLoader`，Apple [要求](https://developer.apple.com/documentation/virtualization/creating-and-running-a-linux-virtual-machine)提供与架构匹配的内核及 initramfs；必须从已核验安装或包制品取得并记录摘要。

固定 Hermes commit 为 `903230b1e23e0c496b28e5d2e8c4f2639cd506b6`。需在隔离环境内核查 Python 3.14.9、固定引擎归档、锁文件和每个依赖制品的来源及摘要，执行依赖检查和实际启动检查。本次没有验证 Linux 制品兼容性。当前 [browser-harness 官方配置](https://raw.githubusercontent.com/browser-use/browser-harness/main/pyproject.toml)仍声明版本 0.1.13 和 `pillow==12.3.0`；[上游 PR 935](https://github.com/browser-use/browser-harness/pull/935)提出 13.0.0，状态为 Open。U2-01 核查确认固定 Hermes 在 Python 3.14 将两者列为基础依赖，锁文件覆盖没有消除发行元数据冲突；`browser_exec` 使用当前解释器调用 `browser_harness.run`。官方兼容发行尚未核实，公开资料文本研究能力继续保留。不得将覆盖安装或依赖检查失败登记为依赖一致。
