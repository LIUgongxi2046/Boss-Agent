# Boss-Agent 安全检查计划

版本0.1.0，2026-10-23，T09/A09，执行责任 T24；目标为已授权的本机独立集成环境和获准模拟资料。状态来源为 `delivery-ledger.json`。检查范围不包含生产系统、第三方攻击、拒绝服务或未授权数据传输。

## 身份、资产与边界

唯一业务主体为 boss-1，维护身份仅处理技术配置和获准模拟输入。联系人没有登录权限。敏感资产包括凭据、私人日历、个人记忆、录音、业务授权、资料原文、持久化状态和备份。服务端身份、SQLite领域事务、nanobot Runtime、Electron主进程及外部模型/语音服务分别检查。

## 执行与证据

使用实际服务、真实 SQLite、当前固定依赖和获准资料，不替代产品响应。低影响拒绝请求与合法业务路径分别执行。记录源码与数据版本、角色、动作、请求编号、实际状态码、业务对象摘要、日志范围和原始产物；不记录凭据或私人正文。外部模型使用已授权样本，必要费用记录实际覆盖。

每项观察核对真实触发、现有控制、影响和复验条件。关键词命中、缺少标题或命名差异不能单独判定漏洞。真实问题记录具体位置与输入条件，修复交由责任任务，随后验证合法操作和拒绝路径。没有实际执行的项目保持 NOT_RUN，缺少外部服务或授权仅影响相应项目。

目前 T11 已有身份、跨角色拒绝、退出、过期、真实模型异常和部分 Electron 隔离证据；这些局部结果不覆盖全部安全矩阵。系统权限、安装包、迁移备份、全部配置和数据路径、完整上下文生命周期仍需执行。发布判定由 T26 按当前证据完成，不作正式认证声明。
