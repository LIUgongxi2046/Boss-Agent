## 完整范围

1. 菜单仅展示准确交付版本中已完成且能够体验的功能。以正式交付记录和实际可用入口映射，不能以PRODUCT_PAGES中存在、部分组件完成或占位页面推断完整功能。侧栏、移动目录、全部页面目录、搜索/快捷入口和通知等导航采用同一映射；未交付入口隐藏，直接旧链接显示清楚的不可用状态并可返回已完成入口。认证、退出、帮助和当前已交付流程必要依赖保持可达，维护入口仅展示其实际可用维护能力。用户验收待确认不等于开发未完成，不能将全部待共同验收功能隐藏。
2. 登录背景沿用蓝绿白、现有Token、Logo和大鹏，使用有层次的浅蓝/浅绿渐变及CSS装饰，主内容保持清晰可读；不新增图片、重做品牌或修改现有吉祥物运动。当前只使用DOM、计算样式和行为检查，视觉判断由用户体验，不主动截图或查看图像。
3. 增加准确文案“测试账号注入”按钮。仅在显式本机测试/演示模式启用，点击后从当前本机受控账号来源填入当前登录入口对应的既有测试账号；默认仍为BOSS，切换技术维护后对应MAINTAINER。仅填充，不自动登录，不跳过密码认证，不修改账号、身份、授权、Runtime或业务数据。失败明确显示原因，不填写伪造成功值。
4. 测试账号与密码不写入源码、前端静态制品、URL、普通日志或持久浏览器存储，不通过通用未认证HTTP接口公开。优先复用本机Electron可信通道和现有凭据读取机制，严格校验当前窗口/主frame/来源及实际启动的演示模式；普通或非测试入口不暴露该能力。最终认证和角色仍由原服务端核查，不新增业务权限。保留正常手动输入及账号密码错误状态。
5. “技术维护”和“认证帮助”在相同状态、窗口及缩放下可见按钮宽度、高度、字号、间距、边框和圆角一致，保持键盘和焦点可用。帮助展开后的正文独立布局，不使两个触发控件尺寸不同；维护切换和返回本人登录继续可用。
6. 登录欢迎区移除指定“本机桌面 · 身份分别核验”整句及其专用空白，不影响现有品牌、欢迎文字、输入、错误和登录状态表达。
