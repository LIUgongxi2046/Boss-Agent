# Boss Agent 操作手册与故障处理

doc_id：DOC-OPS-CURRENT；维护责任：当前主执行者；状态：CURRENT；last_verified：2026-10-28。适用版本：`9cd9888490521242def326f475c93823a68ec95b`及本机未提交修改；入口采用[正式状态](../specs/feature-delivery.json)与[仿真主记录](development/SIMULATION-20261028.md)。完整产品和用户验收继续保持各自状态。

## 1. 登录与工作入口

当前仿真候选使用 `scripts/run_comprehensive_simulation_local.sh`，通过浏览器访问其9082端口。脚本启动 Python 服务，具体资料、制品、配置与端口见[运行环境](运行环境.md)。启动前核查端口和实例是否已有服务；已有用户实例继续保留。通用 Electron 桌面入口为 `scripts/run_boss_local.sh`，两者的资料与前端条件分别检查。

本机演练显式启用账号预填，选择“老板”或“管理员”时读取当前实例对应账号；用户点击登录后建立会话。预填不自动提交。老板使用今日工作、聊天交办、经营关注、会议与资料、任务与承诺；个人设置从账号菜单进入。管理员负责技术配置和获准模拟资料，不能替老板完成本人决定。

## 2. 老板日常操作

| 场景 | 连续操作 | 应核查的结果 |
|---|---|---|
| 安排今日工作 | 打开今日工作，查看业务日期与事项，选择一项并阅读依据；按事项可用操作处理或继续提问 | 日期、负责人、期限和来源来自当前资料；成功操作保存后能够重新读取 |
| 了解经营变化 | 在经营关注选择期间及业务，必要时展开高级查询；应用条件后查看指标和 Boss Agent 提醒，进入分析 | 分析会话采用已应用范围、专题与用途；金额、期间、单位及资料缺口清楚显示 |
| 阅读农业专题 | 从经营范围进入专题，禽畜选择对应用途；查看指标、明细、任务和来源 | 蛋禽、奶畜、肉用牛羊分别使用对应单位；关联任务显示当前状态与反馈 |
| 讨论会议与资料 | 打开会议与资料，选择会议或资料，核查时间、参会人和来源，进入讨论 | 讨论绑定选择的对象和版本；会前准备与会议安排、发送邀请分别处理 |
| 跟进任务与承诺 | 打开任务与承诺，选择任务，核对责任人、期限、反馈和证据，再执行适用的催办、延期、完成或取消 | 收到反馈与本人确认完成分别保存；本人承诺保持独立记录 |
| 阅读长回答 | 在聊天中查看流式回答，向上浏览历史；使用返回最新位置操作继续跟随 | 手动浏览时保持阅读位置；流式结束与业务执行完成分别判断 |
| 更新当前资料 | 使用顶部全局刷新，重新读取当前页面 | 保留筛选与选择；未保存内容按页面提示处理，业务动作不会因刷新重新发送 |

自然语言提问使用当前获准工具与资料。需要改变经营法人、期间、专题或用途时，重新应用范围并进入对应分析；原会话恢复继续采用其原绑定。普通聊天能够查询其他工作资料，经营绑定会话采用对应受限工具。

## 3. 管理员操作与 Agent 方法

| 管理对象 | 当前操作 | 采用与验证 |
|---|---|---|
| 模型连接及运行配置 | 在模型、Runtime 配置页面保存草稿、校验、启用 | 核查当前启用版本、实际模型请求和工具记录；连接校验与真实回答质量分别验证 |
| Prompt | 在 Prompt 版本页面保存、静态校验、启用或停用 | 后续任务读取有效版本与来源；当前运行保留启动时取得的内容，业务动作继续检查当前授权 |
| SOP | 在方法及版本页面选择方法，核查正文、依赖、工具和版本后启用 | 目录启用、依赖满足、上下文采用及模型效果分别检查；方法不签发本人授权 |
| 知识资料 | 通过知识管理入口维护获准来源，核对作者、日期、版本和适用范围 | 当前原文经 FTS5 检索及来源检查后提供；撤销和来源更新影响后续采用 |
| 模拟业务资料与反馈 | 使用对应模拟接口和反馈入口保存资料，核查原回执及对象版本 | 模拟专业反馈、外部送达和本人验收分别记录 |
| 调度与运行记录 | 查看当前技术调度、业务事件、运行、模型请求与工具错误 | CronService 是唯一调度执行者；配置启用和实际通知送达分别验证 |
| 评测 | 在评测页面采用当前任务集并读取尝试结果和证据 | 结构断言与语义质量分别评估；当前没有每次聊天自动完整语义评分的证明 |

方法与 Prompt 的完整机制、适用场景和限制见[Agent 说明](Agent六要素设计与实现说明.md)。管理员不应通过直接编辑 SQLite 代替正式动作。已有账号禁止重复初始化；生成演练资料需要明确选择目标空间与业务时间，保留用户操作。

## 4. FAQ 与故障处理

| 现象 | 核查与处理 |
|---|---|
| 启动提示资料、账号或制品没有准备 | 核对对应启动脚本的目录及 `index.html`；采用正式候选说明准备条件，不覆盖已有账号和资料 |
| 端口已被使用 | 读取监听进程的命令与所属目录；已有用户实例保持，不自动终止未知进程 |
| 无法登录或身份过期 | 核对当前实例、身份选项和账号，再由用户登录；不能将其他实例的令牌用于当前服务 |
| 经营来源或快照变化，返回409 | 刷新当前经营资料，重新应用范围；保留旧请求及历史结果，准备新的分析时重新确认范围 |
| 进入分析后发现专题或用途不同 | 核对当前绑定，从对应专题重新进入；原会话继续使用原来的范围 |
| 模型请求失败或超时 | 查看当前运行的 `stop_reason`、模型请求及工具错误；保留已保存业务结果，核查模型连接和运行预算，不自动换用模型 |
| Agent 到达模型请求预算 | 最后一轮停止新增工具调用，依据已有结果回答并说明未核实内容；核查运行记录是否正常结束 |
| 页面显示资料缺少、PARTIAL 或无数据 | 查看当前来源、期间、权限与缺少字段；这些状态只说明当前可用范围 |
| 来源撤销或过期 | 停止当前采用，通过正式资料维护及来源复核处理；历史记录不恢复旧授权 |
| 保存或发送后连接中断 | 保留原 `client_request_id`，读取原回执和对象；没有取得结果前不重复发送 |
| 模拟消息显示已发送 | 核查 `source_type`、`delivery_state` 与实际外部调用；模拟发件箱记录不能证明外部联系人已收到 |
| 修改 Prompt 后回答没有符合预期 | 核查启用版本、来源有效性、该次上下文采用、实际工具及回答；静态校验通过不能证明模型质量 |
| 语音入口不可用 | 语音任务当前暂停，真实转写与设备权限保持未验收 |

## 5. 资料保护与后续验收

凭据文件、本地 SQLite、会话和用户资料保存在已忽略的受保护目录；技术诊断仅采用必要标识与摘要。维护身份默认不能读取私人正文。恢复检查使用独立资料与端口，不退出用户实例，不切换其制品。

本次文档更新没有新增模型请求、自动认证、资料初始化、进程启动、截图或视觉检查。当前仿真检查只覆盖对应输入和版本；全部72页面的完整业务与交互、备份恢复、设备权限、系统通知、正式安装分发及用户验收，继续按[正式状态](../specs/feature-delivery.json)、[完整任务记录](../delivery-ledger.json)及相应主记录核查。
