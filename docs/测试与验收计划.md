# Boss-Agent 测试与验收计划

版本0.1.0，2026-10-23，T09/A09；执行责任为 T24，状态来源为 `delivery-ledger.json`。当前为设计及用例目录，不表示全部用例已经执行。

## 需求和输入

需求来源为 PRD V1.2.0 第8节、第10.5节及第12节、项目计划第10/13节、当前决策和 `specs/value-validation.json`。`specs/acceptance-cases.json` 逐项维护32个 FR 的64项 AC、每个 FR 继承的 E01—E06、16类管理能力和12项 NFR。展开后包含332项计划检查：64项功能正常及特有异常、192项共同异常、64项管理状态和12项非功能检查。禽畜四种用途、各农业资料关系及全部业务分支还需在其场景内逐项核查，不能以332替代业务明细分母。

每项合法路径需要明确角色、入口、获准资料版本、有效来源、对象状态及必要本人决定。资料缺少时阻塞对应路径，继续其他已满足输入的检查。当前获准 selection 事实可以用于独立执行空间；重置、模型检查与人工检查使用独立副本。新增农业事实遵守项目计划第13.5节。

## 运行身份与记录

每次执行记录 commit、影响结论的源码 SHA256、数据版本、namespace、操作者、实际命令、请求及工具过程、独立断言、保存结果重读、起止时间、费用覆盖和未验证范围。构建、运行服务、数据库及页面必须属于同一集成版本。不得保存凭据、私人正文、录音或内部推理。

| 类型 | 实际核查 | 允许的结论 |
|---|---|---|
| STRUCTURE/STATIC | Schema、需求映射、目录及源码引用 | 对应结构有效 |
| UNIT/API | 真实 SQLite、领域方法和认证接口 | 已执行参数及状态范围有效 |
| SECURITY | 合法动作与未认证/越权拒绝 | 指定角色、资源和方法有效 |
| BUSINESS/INTEGRATION | 页面实际操作、正式保存、重读、后续采用与重启 | 指定业务过程有效 |
| EXTERNAL | 实际模型、转写及其他获准服务 | 已观察外部请求与结果有效 |
| EVAL | 独立质量检查、数值复算、人工配对及全部尝试 | 对应输入集与测量有效 |
| VISUAL | 获准后进行图像比较 | 当前未执行，不登记通过 |

局部成功、安全拒绝、目录存在和模型连接分别记录；它们不能独立满足完整业务验收。

## 执行顺序与断言

1. 核查独立目录、端口、当前进程、数据身份、配置和构建来源。启动失败停止依赖该服务的检查。
2. 运行相关领域检查、完整工程回归、固定前端类型检查与生产构建、凭据及设计资源检查。
3. 在真实 Electron 中执行六类本人入口、16类管理能力、72页面及561状态的适用动作。读取页面映射和版本化状态索引作为完整集合，逐项保存执行状态。
4. 对写入检查当前身份、CAS、撤销、相同编号重读、不同内容冲突、保存后重读、刷新及重启；只读检查来源、范围、正确性、新鲜度及零业务变更。
5. 每项功能独立执行 E01—E06。模型错误、超时、取消、保存后断流和结果未知分别核查，读取原请求后才能决定后续动作。
6. 使用真实 DeepSeek、有效 Prompt/SOP/知识版本与当前工具执行秘书过程；全部十个农业专题和四种禽畜用途使用获准完整资料，数值由原始精度独立复算。
7. 验证所有配置保存、校验、启用、停用、重载和下一任务实际采用。只读管理区域核查所引用的当前配置、状态和权限；不增加无关写入。
8. 验证目标 Mac 的安装、关闭窗口、退出、重启、重复启动、断网、通知、麦克风、休眠恢复、数据迁移和受保护备份恢复。只处理本窗口拥有的进程。
9. 按 VV-T00 执行至少两次独立重置、人工配对、固定及未知变体，保存全部已开始尝试，包括失败、取消和超时。

## 桌面与语音

登录、重新认证、本人和维护界面在1024×768、1280×800、1440×1024及200%缩放逐项检查。外层四边相对内容视口误差不超过1 CSS px，无整页横向滚动；内部内容、键盘、焦点、错误与播报仍需可访问。页面刷新、窗口调整和身份切换重复相同检查。保留 macOS 原生窗口控制。

语音使用获准真实录音和服务。录音操作、系统权限、转写、本人核查和再次明确提交分别留证。检查拒绝和撤销权限、停止采集、重复请求、取消、断网及临时文件清理。当前 Doubao 已观察 HTTP401，服务认证未通过；真实转写及其业务采用保持受阻，不能使用预设文字证明成功。

## 质量、测量与完成

TH-QUALITY 的数值、授权、重复写入、来源属性、完成状态及隐私错误任何一项均阻止对应通过声明。费用采用真实请求及计价出处，缺少用量或价格时总额保持 null。TH-D05、改善幅度、RPO/RTO等未知阈值不自行补充。H35 没有真实观察时保持 INSUFFICIENT_EVIDENCE。

实际结果使用 NOT_RUN/PASS/FAIL/STALE/BLOCKED，记录确切适用范围。`scripts/check_acceptance_inventory.py` 仅验证用例结构与 PRD identifier 集合，语义审查及实际业务执行单独完成。T09正式验收还需要完整设计审查与安全计划，T24负责全量执行，T25负责交接，T26负责独立交付审查。
