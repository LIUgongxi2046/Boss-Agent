## 1. 当前候选提供的行为

| 范围 | 具体行为与依据 |
|---|---|
| 老板工作区 | 今日工作、聊天交办、经营关注、会议与资料、任务与承诺，个人设置采用账号菜单；用户标注与验收要求见 [USER-REVIEW-20261027](development/USER-REVIEW-20261027.md) |
| 经营分析 | 绑定已应用范围与来源，按总览、专题及禽畜用途读取；专题返回当前关联任务与已保存反馈 |
| 模型执行 | 已启用外部连接时，FeatureProvider 调用真实模型；当前仿真记录采用 DeepSeek `deepseek-flash`，最后一轮预算用于形成回答 |
| 资料讨论 | 会议及资料入口携带所选对象、版本与来源，经过原生会话与正式工具继续讨论 |
| 仿真资料 | 生成关联人物、业务日期、会议、交办、本人承诺、申请、反馈及十三个专题和用途；十四类模拟接口具有可读记录 |
| 公开经营基准 | 保留年度报告的原始期间与单位；原始金额核查24项、销量8项；当前月份的模拟业务另外标注 |
