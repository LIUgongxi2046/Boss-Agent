## 当前实施与证据

当前生成器采用统一业务时钟，保存14位联系人、13个专题及用途、12项交办、3项本人承诺、4项申请、4场会议、会面资料、研究、消息与模拟回复、行程、库存与品质追溯。十四项模拟接口均有可读取记录。重复生成保留已保存的本人操作；资料在独立 SQLite 中生成，通过版本核对后在同一事务保存到目标空间。

经营基准采用公开年度报告的24项金额和8项销量，保留原始期间、元与万吨单位、产品合并范围及来源地址。金额采用PDF第200页，主要销量采用第17页，海外销量采用第18页；验证记录同时保存从零开始的页面索引。产品使用“丰泽农牧集团”。历史公开基准与模拟月度经营分别标明；模拟月度毛利计算采用公开饲料业务的成本比例，订单、客户、批次与业务事件继续明确为模拟。

经营详情、会议准备及真实 Agent 共用 `BusinessOverviewAPI.topic_in_transaction`，蛋禽、奶畜与肉用牛羊各自采用当前用途的数值、单位和来源。用途来源的变化会改变经营快照。`businessOverviewRead` 的 `projection` 为 `current`，服务端根据已经绑定的范围选择总览或专题。经营分析按钮在绑定完成后提交问题，原会话恢复保持读取原记录。

`FeatureProvider` 在实际启用的模型调用预算内保留最终回答轮次。最后一轮继续使用真实模型，停止新增工具调用，根据已有工具结果交付回答并说明未核实内容。用户没有指定篇幅时采用简明答复；完整清单、详细内容及明确篇幅继续采用用户要求。
