## F06 · 老板独立催办

- 新增 `boss.assignment.nudge`，从 BOSS 已认证 WebSocket 提交。必须是当前版本、稳定负责人、已单独授权发送且仍在 `WAITING_FEEDBACK` / `IN_PROGRESS` 状态的任务。原始文档、纪要来源、版本或联系人过期均禁止执行。
- 催办拥有**独立于创建和初次发送**的确认及授权，发送正文在 BOSS-only `assignment_nudge` 本地模拟对象中持久化，授权和一般技术审计只保存正文摘要及任务标识。24 小时模拟业务时钟内不允许以新幂等请求重复催办；相同键返回同一条持久结果。
- F06 提供独立“本人核对并模拟催办”动作，F06/N05 `linked_messages` 增加 `ASSIGNMENT_NUDGE` 元信息，能查询 `SENT_SIMULATED` 和 `NOT_VERIFIED`。催办**不修改交办状态或期限**，不代表外部送达或老板确认完成。
- `app/tests/test_boss_assignment_nudge.py` 验证未发送任务拒绝、维护越权、来源撤销、联系人/版本、任务提交结果后的拒绝、24 小时重复防护、再次授权和真实 SQLite 时间线。

## A13 · 保存、校验、采用、启停与手动模拟执行

- `validation/boss_scheduler_config.py` 提供 `boss.scheduler.draft.save`、`draft.validate`、`activate`、`pause`、`resume`、`cancel`、`manual_run` 七类 MAINTAINER-only 操作。
- **保存≠校验≠启用。** 草稿 `DRAFT` 不直接触发调度，`VALIDATED` 按当前已校验规则和计划版本进行确认，只有 `activate` 才把配置应用到 SQLite 当前 `schedule/rules`。所有启停和配置均校验实时版本并同事务持久化；终态 `canceled=True` 的计划不能在原执行空间重新启用。
- 当前有界选型仅允许 `Asia/Shanghai`、`EVENT_OR_TIME`，静默时段 0—23、冷却 0—86400 秒和显式的重要提醒升级开关，不擅自模拟跨国时区、有效计划估时或未验证的复杂表达式。
- 手动执行从当前已批准模拟事件中选择**一个明确事件 ID 与版本**，调用经重构后与自动 Cron 公用的 `ControlStore.dispatch_due_in_transaction`。沿用到期判断、静默、冷却、暂停/取消、事件版本去重和老板已结束任务的抑制规则。已到期事件在 SQLite 记录 `DELIVERED` 仅代表**内部模拟投递**；真实系统/外部通知未验证，下一次运行时间仍为 null。
- `app/webui/MaintainerScheduler.tsx` 承接原始 A13 v6 主视觉和卡片样式，显示当前计划、草稿规则、版本、启用状态、技术动作、模拟事件、真实调度回执和受限的手动运行条件。旧通用只读页已被替换。配置失败后可凭原始幂等 ID 查询结果，不自动扩大角色权限。
- `app/tests/test_boss_scheduler_config.py` 与 `test_v6_scheduler_ui.py` 核查 CAS 冲突、越权、取消不恢复、草稿不启用、事件模拟抑制、手动到期/未到期、重复触发无重复发件、同一 Cron 实现和组件契约。
