日期：2026-10-22；状态：**可编译的语音交互切片，T20/A20 尚未通过验收**。

本轮补齐 `app/webui/BossVoiceAssignment.tsx`，由 `BossDesktop.tsx` 的 F27 实际承载，构建脚本 `scripts/prepare_boss_webui.py` 将其叠加到固定 nanobot WebUI 源码。继续使用 Desktop v6 原有蓝绿白样式、大鹏视觉与右侧信息区，没有以静态 HTML 充当功能。

执行路径为：老板点击录音 → 若在 Electron 中经 `bossDesktop.invoke(request_microphone)` 请求原生 macOS 麦克风授权 → 浏览器 `getUserMedia` 录制 → 录音大小和时长检查（最大 3MB/60 秒） → 用户明确点击“提交转写” → 已认证 `NanobotClient.transcribeAudio` → 文本必须本人审阅和必要修改 → 再次明确提交，进入原生 Agent 会话。

保护措施包括卸载与停止后释放轨道、清理对象 URL、权限拒绝时可退回文本、转写异常保留录音而不假装识别成功、未确认内容不发出 Agent 消息。转写失败时不会显示生成的任务或改变业务状态。

**关键边界：现有 `validation/application.py` 的默认运行配置仍将 transcription.enabled 设为 false；项目没有经过验证的真实语音转写 Provider。** 因此当前 F27 是客户端录音/授权与上游转写协议的开发切片，并非“真实语音转写已可用”。不能为通过验收而擅自启用不确定的外部服务。需要 T07/T15/T20 配好合法真实服务、文件大小限制、Mac 权限、失败重试、语音种类和端到端实测，才能决定 A20 是否通过。

此外，D04 负责人选择、D05 时间选择、D06 未保存草稿提示、D07 无权限提示在此前 React 工作台已实现部分交互，但早期 `page-service-map.json` 仍标记为占位。本轮已修正真实实现映射，仍保留其运行与视觉未通过状态。N01/D08 交由 nanobot 原生认证，并不独立重复开发。
