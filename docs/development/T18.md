## 操作契约（当前只适用于已批准模拟空间 ui-check）

| 操作 | 身份 | 输入的核心业务值 | 结果 |
|---|---|---|---|
| `boss.assignment.create` | BOSS | 目的、唯一负责人、期限/时区、证据、有效会议/事件/来源、独立幂等 ID | OPEN；服务端创建一次有效授权并保存任务 |
| `boss.assignment.send` | BOSS | 当前 task/version、同一负责人、正文、独立幂等 ID | SIMULATED SENT + WAITING_FEEDBACK；发件箱一条 |
| `boss.simulation.feedback` | MAINTAINER | 有效 task/version、指定反馈作者、类型、证据/延期申请 | 进展、EXTENSION_REQUEST 或 RESULT_SUBMITTED；**不直接完成** |
| `boss.assignment.extend` | BOSS | 当前 task/version、有效延期申请、新期限 | 校验新期限晚于原期限；批准前不改变原期限 |
| `boss.assignment.complete` | BOSS | 当前 task/version、RESULT_SUBMITTED 的有效证据反馈 | 仅本人独立确认才变为 COMPLETED_CONFIRMED |
| `boss.assignment.cancel` | BOSS | 当前 task/version、明确取消原因 | CANCELED；历史模拟消息仍可读 |

服务端从当前业务数据集绑定 owner、namespace、引用版本，禁止浏览器自填这些权限字段。授权记录随本次老板操作创建，默认短时有效；模型及维护者无权自行签发老板决定。客户端在不确定结果时复用原幂等 ID；断线不默认重发不同 ID 的写入。
