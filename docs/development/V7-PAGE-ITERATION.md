## 3. 已完成页面记录

### 公共 Shell（报告 2.4）

- 顶部搜索改名为“搜索功能或事项”；删除导航旁重复的“今日／开始对话／语音／通知”快捷条。
- 通知只保留右上角入口，进入 N06；删除左侧重复“全部菜单”，目录由顶部搜索与移动端目录按钮承担。
- 身份显示改为“老板本人／技术管理员”，展开后提供账号与设置、退出登录；不再点击即退出。
- 页面刷新统一为“刷新”；读取中显示“刷新中…”；认证状态页不显示业务刷新。
- 导航分组、收起导航、⌘K 目录、未保存离开保护保持原行为。

### N01 身份登录

- 身份入口改为“老板／管理员”，说明登录后按账号身份进入工作区。
- 登录页显示实例地址、环境类型和账号取得说明。
- 主按钮改为“登录／重新登录”；过期状态只保留一个重新登录入口，并说明已提交请求只查询结果。
- 空账号、空密码分别聚焦对应字段；账号密码格式错误、认证拒绝、连接失败、服务未就绪分别说明。
- 已登录状态页的退出按钮改为“退出登录”。

### N02 聊天交办

- 会话选择收进历史对话列表；删除“新建会话”重复按钮与“当前会话”下拉。
- 历史开合统一为“历史对话／收起历史”；返回按钮按来源显示“返回交办／返回经营关注”等，直接进入聊天时不显示返回。
- “查看完整执行”改为“查看过程”，仅存在运行时显示；“读取原执行结果”改为“刷新结果”。
- 必要决定与授权入口改为“核对并确认”“查看授权详情”。
- 来源入口统一为“查看依据”；产物入口改为“打开交办”；经营查询入口改为“查看查询明细”。

### N03 经营关注

- 初次进入自动读取默认合法范围；查询按钮改为“查询”，读取中显示“查询中…”并可“停止查询”。
- 选中专题操作改为“查看资料范围”，无选择时不显示。
- 查询明细与讨论入口改为“查看查询明细”“让大鹏分析”；删除固定“查看禽类与反刍”入口。
- 来源入口改为“查看依据”；用途切换保留独立状态。

### N04 会议与资料

- 查询按钮改为“筛选”，新增“清除筛选”；日期改为起始／结束范围；材料状态只对适用分类显示。
- 列表行去掉 ID 作为按钮名称；未选择记录时不再显示整排禁用业务按钮。
- “准备会前材料”“讨论这场会议／让大鹏整理这份资料”按记录类型显示；“阅读原文／打开纪要／查看历史决定”移入选中记录详情。
- 删除页内重复刷新，改由公共“刷新”传入 `refreshVersion` 重读。

### N05 任务与承诺

- 页签改为“全部／我的承诺／我交办的”，等待反馈与待我验收进入筛选区；计数口径统一。
- 状态筛选使用业务名称，逾期按模拟业务时钟计算；“筛选任务”替换“查询 / 应用”。
- 列表行名称改为“事项＋负责人＋期限＋最新状态”，去掉任务 ID；当前进展显示最新反馈时间。

### N06 通知中心

## 3.1 本批未实施与依赖

- N07／N08 免打扰分钟级输入、跨日时段保存需要服务字段从整点小时改为带分钟时间；当前页面只展示整点并说明实际保存范围。
- N09 执行时区选择需要计划服务接受 `Asia/Shanghai` 以外的 IANA 时区；当前页面明确显示服务只接受该时区。
- N04 独立“打开会议”动作、来源名称显示需要服务新增动作与来源名称字段。
- N05 负责人／会议按名称选择需要任务投影补充姓名、组织、会议标题；准备催办消息需要 N05 到 F08 的预填入口。
- N06 业务名称、负责人、期限与申请类目标页需要通知投影补充字段。
- F02 “查看我的关注要求”与“提醒设置”完整合并需要 N07／N08 承接技术阈值只读与提醒设置区域；当前保留原规则弹窗与分离入口。
- F03 单期／期间比较方式需要查询服务提供显式模式；当前保留现有查询方式与期间条件。
- F24 逐项产物链接、停止未执行步骤的步骤级预览需要运行服务补充动作级数据。
