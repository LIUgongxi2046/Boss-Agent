## 2. 页面目录与导航

全部 B01—B06、M01—M04 和 X01—X06 在电脑桌面应用内承载，系统标题栏与窗口操作继承目标 OS 约定；产品内容无需浏览器地址栏。手机及平板专属适配不属于当前范围。窗口正常显示、隐藏、退出、休眠与恢复按 PRD 第 10.5 节执行，界面明确本地服务和调度状态；关闭前的未保存内容提示提供继续编辑与放弃当前编辑选项，放弃编辑不撤销已执行业务动作。后台运行默认关闭，启用时提供可达的重新打开与完整退出入口。

录音前请求系统麦克风权限；拒绝或撤销后停止采集并显示文字输入入口。系统通知默认只有应用名、事项类别及返回入口，通知权限关闭时保留应用内通知；打开通知重新校验身份及资源权限。文件选择、保存及外部来源由获准桌面能力执行，IPC 不接受任意命令或任意文件访问。安装启动、网络中断及恢复状态沿用 S00—S10 的适用表达，实际业务状态保持独立。

### 2.4 导航与对象连续性

每次跳转保留当前老板、数据集、execution_namespace、事项/事件 ID、会话 ID、来源版本和返回位置。认证身份由服务端确定，地址参数不能授予权限。私人正文、录音和密钥不进入地址、桌面导航历史、WebView 通用缓存或系统通知。

查看依据、会议或交办后，“返回当前事项”恢复原日期、筛选、滚动位置与焦点，同时重新查询当前进展；资料变化时提示“依据已更新，需要复核”，保留历史版本入口。跨命名空间打开旧通知或旧会话时，明确显示历史归属与只读状态，不能把历史对象提交给当前空间。

刷新只恢复查询和编辑上下文，不重新提交写入。运行 ID 已取得时依据 run_id 查询；连接中断且执行情况未知时进入 RECONCILING。会话切换清除未确认录音输入和对象选择，未保存文字通过 X05 处理；不从其他会话推定授权。

## 4. 通用操作、授权与结果规则

### 4.1 操作模型

每个操作由“当前主体、输入、目标对象、内容版本、授权、处理状态、取消能力、结果地址”共同定义。第 6—7 节逐项登记输入和对象，操作 ID 连接本节行为。读取使用当前获准范围；写入由服务端再次检查 owner_id、action、target_id、内容版本、有效期、撤销及 execution_namespace。

| 授权类型 | 页面必须显示的内容 | 执行与禁止条件 |
|---|---|---|
| Q 查询及材料整理 | 对象、条件、资料范围和读取版本 | 获准范围内直接执行，无通用二次确认；来源正文中的指令不增加权限 |
| D 草稿及准备 | 草稿对象、来源与未发送状态 | 保存草稿按现有授权；草稿不自动发送或成为长期个人要求 |
| B 本人业务动作 | 动作、对象、收件人/负责人、正文/金额/币种/时间、附件、版本、范围、后果及有效授权引用 | 已明确且有效直接执行；条件缺少或改变只请求相应决定；没有默认同意、默认完成或默认全选 |
| T 技术维护 | 配置类别、版本、获准资源、影响范围、技术权限和采用状态 | 维护只能变更技术配置及获准模拟资料；涉及本人目标、私人设置与业务决定时拒绝 |

X02 持续显示“依据你的当前指令执行”及授权所指内容。授权有效时不强制增加弹窗步骤。授权撤销针对尚未执行动作，撤销结果可重读；已执行变更需要新的有效业务指令。

### 4.3 写入、错误与中断

提交时按钮进入进行状态，同一意图绑定同一幂等标识；阻止连点只属于界面反馈，服务端仍须去重。相同标识与不同内容必须拒绝，不能覆盖原操作。写入后查询正式对象，返回对象 ID、版本、真实处理时间、业务时间、授权引用与结果入口，才能展示“已保存”“已发送”等结果。

保存、发送、索引、通知分别显示进度和结果。模型后续表达失败时，已保存任务和消息继续显示。执行不确定时提供“查询执行结果”，确认未执行且原授权有效后才可发起新尝试。失败展示业务可理解的原因及继续条件，不吞掉错误，不自动更换模型或提供预设答案。

## 5. 页面与业务状态矩阵

### 5.1 所有 48 个区域继承的页面状态

| 状态 ID | 触发与内容 | 可用操作、取消及恢复 | 可访问性反馈 |
|---|---|---|---|
| S00 未加载 | 首次进入，尚未提交查询 | 显示必需条件和开始操作；不显示经营数字 | 标题与表单标签可读，当前区域非忙碌 |
| S01 加载中 | 读取数据或恢复会话 | 保留页面标题、查询范围和前次结果时间；取消读取或离开 | `aria-busy=true`；进度区域 `role=status`，不移动已有焦点 |
| S02 空内容 | 请求成功且当前范围确实没有对象 | 显示范围与截至时间；提供创建/更改条件等获准操作；无写入需求时仅返回 | 不把来源未更新、无权限或失败显示为空；不使用装饰图代替文字 |
| S03 运行中 | 实际 run_id 或动作执行事件已返回 | 显示实际步骤、开始时间、已执行项、可取消范围；不生成虚构百分比 | `aria-live=polite` 播报关键步骤，流式字符不逐字打断 |
| S04 待输入 | 缺少对象、材料、必要决定或转写核查 | 聚焦缺少条件；保留已有输入与成果；可补充或取消未执行步骤 | 错误与字段以 `aria-describedby` 关联，汇总可定位首个问题 |
| S05 完成 | 查询已返回或写入已重读 | 展示具体结果、对象版本、入口及剩余事项；返回原上下文 | 状态文字明确具体对象；不以通用绿色“完成”替代业务终态 |
| S06 失败 | 上游、保存、权限以外的实际错误 | 展示原因、失败步骤、已执行/未执行清单；重查、补充或获准新尝试 | 阻断错误使用 `role=alert`；不能仅用 Toast 保存关键错误 |
| S07 无权限 | 未认证、权限撤销、维护越权或对象范围不足 | 不请求或展示受限正文、标题、附件、录音与摘要；提供返回或重新认证 | 标题“无法访问此内容”，焦点在可读说明；服务端拒绝仍需实际验证 |
| S08 部分资料/需要复核 | 来源未同步、冲突、失效或版本变化 | 明确范围、截至时间、有效部分与缺少项；打开历史或读取当前版本 | 可读警告持续存在；不表示完整覆盖或零值 |
| S09 结果核查中 | 请求中断且写入结果未知，execution_state=RECONCILING | 查询原执行记录；禁止再次发送同一业务动作；允许离开后继续查询 | 播报“正在核查执行结果”，保留 run_id 与已知事实 |
| S10 已取消/历史只读 | 运行或业务对象取消、旧空间或终态对象 | 展示取消范围、历史结果及获准新建入口；不恢复催办 | 显示文字原因和返回入口，禁用操作说明原因 |

S00—S10 对全部来源区域适用。只读区域的 S03 表示查询/检索运行；S10 表示取消读取或历史只读，未增加业务取消动作。没有业务写入的区域检查零业务变更。未保存编辑状态与页面状态独立，统一使用 X05。
