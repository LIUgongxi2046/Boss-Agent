## 3. 构建与启动条件

通用研发准备命令如下，安装依赖及获取固定上游需要对应网络条件：

```bash
uv sync --locked --project validation
validation/.venv/bin/python scripts/prepare_boss_webui.py --build
npm --prefix validation/desktop ci
```

`prepare_boss_webui.py` 检查上游 commit、72页面目录与561状态关联，复制 `app/webui/` 的模块，应用认证与原生补丁，执行依赖安装和构建。构建输出默认制品及 `.work/product/boss-build-manifest.json`、`boss-native-patches.json`、`boss-compiled-build.json`。构建结果需要结合当前源码和未提交修改核查，不能只使用其中的 Git commit 代表全部工作目录内容。

指定仿真制品使用活动主记录中的独立输出命令；通用构建不会自动更新该目录。本次只核查脚本和已有构建日志，没有运行准备脚本、重新安装依赖或覆盖制品。

| 启动条件 | 实际要求 |
|---|---|
| Python | `validation/.venv/bin/python` 存在且依赖完整 |
| 模型凭据 | 通用入口检查本机凭据文件并调用 `configure_local_deepseek.py`；配置只引用受保护文件，不提交秘密值 |
| 账号 | 对应应用目录存在 `accounts/accounts.sqlite`，初始化通过 `provision_boss_accounts.py`，重复创建拒绝覆盖 |
| 浏览器候选 | 对应业务 SQLite、账号和 `index.html` 已准备；底层模型、原生配置与端口继续由应用校验 |
| Electron | `validation/desktop/node_modules` 存在；宿主按当前目录和端口连接服务 |
| 端口与实例 | 启动前核查监听进程、命令与资料目录；已有用户实例保持，不自动终止或改用其他端口 |

## 4. 配置与资料范围

| 变量或文件 | 条件与含义 |
|---|---|
| `BOSS_PRODUCT_UI` | `1` 启用产品服务、账号认证、产品工具与 Runtime |
| `BOSS_APPLICATION_WORK_DIR` | 当前工程 `validation/.work/` 的直接子目录，必须为绝对路径；默认 `application` |
| `BOSS_APPLICATION_PORTS` | 恰好包含 `business`、`webui`、`gateway` 的 JSON 对象；不同整数，范围1024—65535 |
| `BOSS_PRODUCT_FRONTEND_DIR` | 当前工程内包含 `index.html` 的绝对路径；默认通用制品 |
| `BOSS_EXECUTION_NAMESPACE` | 当前执行空间，由服务端按 `boss_execution_scope` 核查；初始空间为 `ui-check` |
| `BOSS_EXECUTION_SCOPE` | 可用值由 `application.py` 检查；影响 MVP 及优先迭代路径，不能随意互换候选 |
| `BOSS_DEMO_ACCOUNT_INJECTION` | `1` 允许本机演练登录表单预填，登录仍由用户点击 |
| `BOSS_REVIEW_RUNTIME_SETUP` | `1` 对满足初始条件的演练实例执行 `configure_review_runtime`，保存、校验并启用当前可用工具和投影 |
| `validation/connection.json` | 本机模型连接引用，权限0600；秘密值不写入文档 |
| `<应用目录>/business.sqlite` | 业务对象、来源、授权、回执、配置与运行记录 |
| `<应用目录>/accounts/` | `accounts.sqlite` 与 `credentials.json`，文件0600、目录0700 |
| 原生目录 | `ui-check` 采用应用目录，其他空间采用 `<应用目录>/spaces/<namespace>`；包含配置、工作资料、会话、诊断与Cron |

初始模型配置为 `deepseek-flash`、12轮、4096输出token、Asia/Shanghai，Dream关闭、语音关闭、空闲压缩间隔为零。实际模型连接、时限及工具范围采用当前启用的持久配置；仿真主记录已有300秒时限和配置版本的限定证据。FeatureProvider 已启用外部连接时调用真实模型；显式模拟 Provider 按对应模式单独记录。

`application.py` 对已保存端口与指定端口不一致、原生目录不属于当前空间、执行空间没有正式资料等条件直接报告错误。参数变更不会自动迁移旧配置和资料。已有账号、会话、SQLite与当前用户运行进程继续保留。
