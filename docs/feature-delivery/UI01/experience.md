# UI01 体验入口

双击scripts/run_ui01.command。该入口沿用既有MVP资料与账号，开启当前明确授权的本机演示能力，从采购成本协调页面进入。当前体验窗口和资料保持原状态；准备切换新界面时，由本人关闭原桌面后启动新入口。

1. 登录页默认本人入口。点击“测试账号注入”只填入当前入口的既有账号和密码，随后点击“登录”或“重新认证”通过原认证服务。
2. 点击“技术维护”后可注入对应维护账号；“返回本人登录”清空原输入并切换身份。手动输入继续可用，密码错误显示原认证提示。
3. 点击“认证帮助”展开正文，两个入口按钮尺寸保持一致。背景采用现有蓝绿白颜色与CSS渐变，品牌和大鹏运动保持；外观由本人实际体验确认。
4. 本人侧栏与目录仅显示已交付的采购成本协调、经营查询、两个业务报告、经营提醒、交办、任务与承诺、通知中心、本人通知设置和计划。维护目录仅显示相应资料、场景/反馈、运行配置、调度规则及记录；来源、负责人和时间依赖通过原业务按钮进入。未交付旧链接显示清楚的不可用状态。

普通或非演示入口不显示账号注入；账号通过本机受控通道读取，不写入静态制品、日志、URL或浏览器持久存储。启动不会自动修改配置、规则、事件或账号。当前业务功能继承FC04准确交付，系统通知实际为系统拒绝，应用内提醒仍可使用。UI01七项及FC04二十项开发验证已完成，用户共同验收独立待确认；后续业务保持暂停。
