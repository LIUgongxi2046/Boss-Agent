# 今日工作设计依据与当前测量

采用Boss-Agent-Desktop-Complete-v6/pages/F01-今日工作.html、design-v6-panels.js的home、design-v6.js、design-v6.css、style.css、页面配置和design-tokens.json。当前范围为原18项及F01-D01—D12必要设计事项；视觉与用户验收保持NOT_RUN。

rework-design.json与rework-header.json沿用准确候选8cabf2c的各18组同环境记录，分别覆盖1440×1024、1280×800、1024×768的100%/200%及1250、1050、700、690附近阈值。记录包含实际行数、展开状态、scrollTop、client/offset/scroll宽度、最终计算样式、位置尺寸及悬停/焦点；分类按相同选中/未选中状态比较。除Dialog布局外前端组件源码与该候选保持，报告保留原始manifest及摘要。

当前制品的rework-dialogs.json保存六种窗口与缩放下真实来源、会议Dialog共12组。参考为原加载页面实际打开的公共Modal；采集遮罩、实际定位容器、内容与文字角色。位置比较包括x及width；定位层采用原grid与20px内距，真实关闭覆盖Escape、关闭按钮、外部点击及返回焦点。当前制品和参考均通过隐藏Electron加载，不使用截图或图像工具。
