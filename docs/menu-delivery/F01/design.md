# MENU-F01 设计与状态映射

CURRENT；2026-10-24；MENU-F01-N3。完整范围为正式工单C01—C18；原设计HTML、页面配置、实际加载的design-v6-panels.js/home及design-v6.js共同提供结构依据。原设计和当前页面均通过隐藏Electron读取DOM、计算样式和位置尺寸，没有截图、图像查看或像素相似度结论。视觉及用户验收待确认。

## 区域与数值

| 原设计依据 | 当前区域及数据 | 核查与适用差异 |
|---|---|---|
| v6公共导航、标题、品牌和大鹏 | 继续采用已交付UI02公共Shell，首页标题为今日工作；采购成本协调提供独立入口 | 当前菜单决定要求同一Shell；原设计预览工具、示例身份和静态状态选择不进入产品 |
| home业务日期与资料范围；三列表单 | 主列首个Panel；业务日期、IANA时区、来源截至及清单读取时间；更新当前事项 | 采用正式业务时钟；来源截至缺少时说明缺口，不用本机读取时间补充。1050px以下表单两列、700px以下单列 |
| 原HTML的boardgrid与home三类Tab | 待决定、待协调、需要知晓三张分类卡片，实际数量及切换选择 | 卡片形式来自原HTML；操作采用home分类语义，计数与表格来自同一正式View；未读取数量保持未知 |
| 原HTML本人事项表格；home事项/排序 | 主列事项表格：标题、处理人、期限、状态、参与原因、排序理由、上移/下移；每页10项 | 表格形式及分页来自原HTML；保存当前本人次序使用正式CAS与同编号只读恢复。表格内部滚动保留完整内容，操作目标44px |
| home自然语言输入位于事项之后 | 现在就交给大鹏；自然问题和发送任务按钮 | 文案来自原HTML，顺序采用实际加载的home。输入进入现有原生会话与同一Runtime；语音维持用户暂停 |
| home右侧选中事项与关联对象 | 右列首个Panel，展示对象/版本、负责人/期限/状态、时间/时区/地点、当前风险和已有措施；讨论、依据、交办及合法会议 | 当前正文全部来自同一清单detail/source；来源和会议采用共享Dialog，关闭恢复触发焦点；无合法关联明确说明 |
| 原HTML关注、来源与页面配置会议/承诺/冲突/覆盖 | 右列关注、会议与承诺、时间冲突、来源与依据、目标要求 | 明确八类输入的提供/纳入/未纳入数量、未知完整范围、来源截至与更新。私人正文不进入地址、日志或普通持久缓存 |
| home保存与返回 | 列表保存区域与当前进展/查询记录，保留原生会话、运行、原编号及结果入口 | 当前选中项、日期、分类、滚动和焦点保存在受控组件内；刷新只读取安全标识对应结果，不自动提交 |

实际加载的原设计主列与右列为minmax(0,1fr)/310px；1250px以下右列260px，1050px以下单列。当前采用相同阈值、14px列间距、13px主列间距及18px/20px卡片内距。700px以下采用15px内距。原预览卡片15px圆角，当前按design-tokens.json采用14px；输入9px、焦点2px、正文16px/24px、辅助14px/22px及44px操作目标延续统一参数。外层窗口由UI02公共Shell承载，原预览的目录和状态工具不占用产品正文空间。

原设计六组实际尺寸记录见evidence/menu-delivery/F01/reference-dom.json；当前六组位置、尺寸、列结构、间距、滚动和行为证据见同目录behavior.json。窗口为1440×1024、1280×800、1024×768，各自100%和200%。判断依据包含区域、层级、列宽、字段、动作和返回路径；颜色及字号只构成其中一部分。

## 状态与身份

| 状态或操作 | 当前实现 |
|---|---|
| 未读取/加载/缺少输入 | 数量未知、实际读取状态、业务日期及IANA校验；保留范围与未提交问题 |
| 当前分类空内容 | 同一投影当前分类没有记录；持续显示来源覆盖，不宣称完整范围没有事项 |
| 部分覆盖/未同步/未设目标 | 正式input_coverage、source_coverage、missing_sources及profile分别呈现 |
| 当前可采用/历史需复核 | list.adoption_state决定详情和操作；历史失效不提供当前正文或来源操作 |
| 进行中/未知/失败/取消 | 读取原生绑定、原晨间请求和实际Runtime终态；未知不重放；已保存清单与失败运行分别显示 |
| 排序冲突/保存失败 | CAS拒绝保留编辑与未保存标识；重新读取与明确放弃分别提供；原编号仅查询回执 |
| 来源/选中对象较早响应 | AbortController、请求代次和清单/事项/版本校验；实际延迟响应检查拒绝覆盖新选择 |
| 离开/返回 | D06保护未保存交办及首页输入；共享Dialog和D06关闭后恢复当前触发位置及焦点 |
| 本人/维护/未认证 | 身份由服务端确定；正式领域、原生绑定、消息逐轮证明和读取分别鉴权；模型没有本人确认入口 |

当前验证状态以integration.md及正式状态文件为准；本文件不单独登记菜单完成。
