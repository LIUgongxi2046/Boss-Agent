# 今日工作独立体验

使用scripts/run_menu_f01_rework.command。独立前端为menu-f01-rework-n3-dist，资料为validation/.work/menu-f01-rework-experience，端口10621/10622/20621；运行状态采用当前本机应用记录。原F01、N02、UI02和MVP体验保持独立。

登录页面选择本人或技术维护，点击“测试账号注入”。受控Electron主窗口仅读取当前应用accounts/credentials.json对应角色的既有账号密码并填入表单；随后由使用者点击登录。密码不进入URL、日志、静态制品或浏览器持久存储。

本人登录后进入今日工作。核查业务日期、IANA时区和资料截至时间，点击“更新当前事项”。三类按钮显示同一资料范围的数量，点击分类可以筛选，再次点击当前分类查看全部。完整覆盖范围、未纳入原因、会议与承诺和查询记录位于“保存与返回→查看资料与业务记录”。资料缺少与没有记录分别显示。

输入晨间问题并点击“发送任务”，进入连续会话。问题由本人明确提交，当前日期和资料引用由正式服务绑定。返回今日工作后选择事项，右侧读取同一清单和来源版本；查看依据、关联会议或准备交办。来源及会议关闭后恢复原控件焦点，刷新会话后返回仍核查原事项与版本。

选择事项后可点击上移或下移，也可以在事项上使用Alt+方向键调整。点击“本人确认保存当前次序”提交实际保存；“查看排序依据与保存结果”提供完整依据、放弃编辑和原编号查询。结果尚未确认时，使用原编号读取，不重新提交。

“继续讨论”在没有问题文字时聚焦输入区域。填写当前问题后再次点击，由本人提交当前事项的引用。准备交办只进入准备流程；创建、发送和完成确认分别要求本人操作。未保存编辑通过既有D06处理。

语音输入暂停；外部接口采用SIMULATED_FIRST。当前资料来自正式应用服务中的获准模拟范围，不代表完整外部经营资料。用户验收与视觉体验仍待使用者确认。
