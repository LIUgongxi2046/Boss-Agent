## 业务与状态规则

所有事实、实际工具参数及结果均来自当前本人获准空间；服务端确定 owner/namespace/dataset、当前来源和对象版本。自然语言不授予权限，模型不能构造本人确认字段或代替本人批准。当前有效明确指令可以直接执行其匹配动作；缺少或改变联系人、正文、附件、范围及版本等决定性条件才请求必要决定，不要求每次重复确认。

草稿、READY/WAITING_AUTH、SENDING/SENT、delivery_state、reply 和关联业务状态分别呈现；模拟发件箱保存后才能显示已模拟发送。未知发送不能自动重新发送。会话与 Runtime 结束不改变交办终态；取消、失败或模型后续表达失败后，已保存对象与消息继续可读。

Runtime 继续使用同一实际 Nanobot AgentLoop、原生 ClientProvider、传输和注册器，按当前有效配置固定版本并消费正式工具结果。SIMULATED_FIRST 显式，当前不新增真实模型或外部请求，不使用设计标签、预设业务答案或静态结果替代运行。现有已交付晨间、采购、经营及交办能力按准确范围复用；新问法和补充条件必须影响实际参数，必要语义缺少时显示具体待输入或未支持条件，不能伪报已经处理。

适用 S00未加载、S01加载、S02当前范围空内容、S03运行、S04必要输入、S05具体结果、S06失败、S07无权限、S08部分资料/复核、S09结果核查、S10取消/历史只读。每种状态分别记录字段、当前可用动作、取消范围与恢复方式；D06、D07、D08随当前路径采用。未读取、无权限和失败均不能显示为空数据。

BDD正常路径：Given 本人身份、当前有效资料及已启用工具；When 开始会话、提交当前问题、补充实际附件、连续追问并查看来源/任务，按合法当前授权保存草稿及模拟发送；Then 实际会话/运行/工具参数对应本次意图，消息及任务版本可重读，来源和产物可打开并返回原消息，回复引用一致，刷新和同库重开保持，零重复业务动作。

BDD异常路径：Given 必要对象缺少、同名联系人、来源变化、在途运行或未知写入；When 取消、断网、并发、重复、越权、上游失败与下游失败分别发生；Then 当前原因和已执行项明确，输入保留，原编号只读核查，模型没有授权提升，没有自动更换模型或重放，已保存结果可读，维护无法获得私人正文。
