## 二、共用 G01—G06

**G01 导航与返回**：老板快捷入口（今日、开始对话、语音、通知）、独立技术维护导航、内容对象链接、来源页面返回参数；使用 `sessionStorage` 尝试恢复每页草稿输入。列表分页/焦点恢复在原型中体现交互规则，正式系统需实测。

**G02 文字与控件**：在保留原图视觉语言的基础上，为新版组件应用 16px/24px 正文、14px/22px 说明、44px 控件、2px 焦点轮廓；旧页面少量紧凑信息保留较小辅助字号，建议落地时继续逐项检查 WCAG 对比度。

**G03 窗口布局**：1440×1024 2x 主稿，另有 1x；抽测 1280×800、1024×768、较窄窗口，侧栏在窄屏收缩、区域转一列、正文可滚动。真实 200% 浏览器缩放及系统宿主窗口仍需实机验证。

**G04 输入与反馈**：21 个核心页面采用文字/数字/日期/下拉等控件与焦点、必填提示，演示保存、授权、验证和取消的区别；所有模拟按钮只出现“设计预览”反馈，不会实际操作真实业务。

**G05 焦点与动画**：可见键盘焦点、弹层关闭焦点恢复、`prefers-reduced-motion` 关闭循环动效。屏幕阅读器完整语义仍需用户测试。

**G06 品牌与素材**：全站共用 v6 Tokens 和已有大鹏透明素材；已有动效沿用，未宣称取得海大官方 VI 或第三方图标许可。

## 三、状态与预览

原始 **561 条桌面 S00—S10 状态提示词**已逐条链接至对应主页面的状态切换入口，状态标题及说明源自用户最初压缩包。共用状态承载于共享组件和设计提示卡，21 个专项页面另有更具体的业务组件。**561 条状态并非 561 张独立图片，尚未逐张进行设计验收。** `states/` 提供 12 张关键状态示例图。

共享系统状态：SYS-STARTUP、SYS-CLOSE、SYS-EXIT、SYS-RESTORE、SYS-NETWORK、SYS-NOTIFICATION、SYS-MICROPHONE、SYS-FILE，已提供模拟弹层与操作说明，但未绑定 T02 系统宿主。

目录提供 11 条根据本次清单推导的**建议演示路径**；因 PRD V1.2.0 与《交互与页面规范 V1.2.0》原文件未随本次附件提供，不能认定已经完成正式 P01—P11 定义及验收。

## 四、需要实际验证 / 未完成项

- **正式 PRD 与路径验证**：需要 PRD V1.2.0、交互与页面规范 V1.2.0 及来源审查原文，以核对 48 个来源区域、P01—P11、FR/AC 全部业务细则。

- **真实动作与权限**：需要业务后端绑定与测试，录音、文件选择、系统通知、完整退出、安装、休眠唤醒及调度需要 T02 宿主证据。

- **实际交互**：目前是离线设计演示；复杂页面的保存冲突、并发授权、分页恢复、屏幕阅读器及 200% 缩放需前端实现后完整 QA。

- **561 状态验收**：可以从对应 HTML 切换展示设计状态，但尚未为所有状态制作独立 2x PNG 或逐项完成视觉/业务验收。

- **品牌素材**：Boss Agent Logo 与大鹏为本会话原型素材，正式使用前需确定商标、著作权与相关视觉使用授权。

## 五、交付目录

`index.html`：72 页可搜索预览图库与路径；`pages/`：72 可编辑 HTML；`images/`：72 张 2880×2048 PNG；`images-1x/`：72 张 1440×1024 PNG；`states/`：关键状态截图；`design-v6.css/js`：统一设计系统与交互原型；`design-tokens.json`；`meta/`：来源映射、561 状态、修改清单、QA、资产清单；`animation/`：原有 6 组大鹏动效；`设计审阅-v6.pdf`：可检视 PDF。

## 六、设计使用说明

解压后先打开 `index.html`，搜索页面编号或名称；打开“交互预览”，在页内顶部选择状态、编辑字段、打开关联入口。浏览器不允许本地 iframe 时，可独立打开 `pages/` 下的 HTML，或在解压目录启动本地静态文件服务。所有按钮只模拟设计状态，不会接入生产系统。
