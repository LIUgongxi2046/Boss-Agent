# 高清桌面图标提示词

工具为imagegen内置工具。正式图标使用蓝绿白品牌，单个居中的简洁大鹏飞鸟标志，蓝色主体与绿色羽翼，适当包含抽象字母B的形态；专业、克制、清晰几何，大块色面与轻微立体层次，白色圆角方形底板，外部透明，平滑连续轮廓。正面视角、正方形高清master，不添加文字、口号、水印或场景。

正式master为`../../validation/desktop/branding/boss-agent-hd.png`，1254×1254。开发运行PNG为同目录boss-agent.png；ICNS由同一master转换，包含16—1024像素版本。吉祥物素材继续引用Desktop v6原始资源。
