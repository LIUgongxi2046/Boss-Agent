# T27 登录与桌面设计

依据原始项目计划13.12、PRD FR-26/28/32、HLD C-GATE、LLD 身份规则和 Desktop v6 design-tokens.json。采用既有蓝绿白界面、Logo和大鹏，范围为 N01/D08 与桌面品牌配置。没有新增业务页面。

品牌说明“老板的AI助理”；主标题“公司信息了如指掌，工作推进有条不紊。”；标识“内测版本”。吉祥物依据设计稿原始dapeng-front.png生成1774×887透明图集，四列两行展示八帧扑翼，0.96秒完成一次循环，保持既有角色、配色和比例。通过CSS motion path及Web Animations沿四段连续Bezier曲线环绕整个可见登录视口，每个周期随机选择曲线控制点。连接位置保持相同切线，按70—84 CSS px/s匀速前进，周期长度由路径长度确定。

使用SVGPathElement.getPointAtLength读取实际切线，每帧同步左右朝向与爬升姿态。侧面姿态的俯仰范围约±17度，变化速度不超过45度/秒；正面转弯姿态的倾斜范围约±9度。两个姿态复用同一扑翼图集，根据转弯角度连续混合，使用plus-lighter保持颜色，转弯时保留完整可见的正面形象。远处缩放0.62，近处缩放0.86—0.94；摄像机距离随飞行相位连续变化，通过距离倒数计算透视缩放，接近与远离的连接位置保持连续速度。动画层位于登录内容前景，不接收指针事件，账号输入、按钮与键盘操作保持可用。调整窗口时重新计算边界，页面不可见时暂停位移、朝向与扑翼。系统减少动态效果时仅展示原始dapeng-front.png，取消飞行动画。

右侧默认本人账号密码；下方同一行展示“技术维护”和“认证帮助”。维护入口切换表单标题，提供“返回本人登录”，服务端核查账号真实角色。切换清空密码和错误并恢复账号焦点。登录卡片、颜色、字号与页面布局继续继承Desktop v6。

颜色、字体、边框、阴影沿用 boss-v6.css：品牌蓝 #005BAC、深蓝 #073B70、绿色 #5CA63B、操作蓝 #0968EA、正文 #172B4D、次要文字 #52647A、边框 #DCE4ED、白色卡片。账号和密码分别使用独立字段容器，标签与输入框间距8px，字段之间及提交按钮之前间距24px。输入圆角9px，卡片14px，正文16/24px，说明14/22px，控件至少44px，焦点2px。1440×1024、1280×800、1024×768及200%缩放保持根容器填满内容视口，内部滚动，不产生横向页面滚动。

状态覆盖：初始、账号缺少、密码缺少、密码显示/隐藏、提交加载、重复提交禁止、认证拒绝、服务连接错误、过期、重新认证、帮助展开、维护切换、资源错误、减少动态效果设置变化。登录成功由现有公共 Shell 接收会话；退出和过期由公共认证生命周期处理。全部用户错误通过 role=alert，连接状态通过 aria-live，表单支持键盘和自动填充。

账号存储使用独立本机 SQLite；用户名唯一，角色固定为 BOSS/MAINTAINER，密码采用 bcrypt 5.0.0、随机 salt、cost12。初始化产生两个真实本机账号及独立随机密码，摘要和明文文件权限0600、目录0700，路径必须在 Git 忽略的 .work 内。重复初始化明确拒绝覆盖。身份范围由数据库确定，客户端 expected role 仅限制所选入口。错误密码与未知账号返回相同拒绝结果。

GET /webui/bootstrap 通过 X-Boss-Username、X-Boss-Password、X-Boss-Role 发送账号请求；账号及密码不进入URL和浏览器存储。成功后仍由原有 nanobot 发放 token；后续 bootstrap 使用 Authorization Bearer API token，核查原有 token 有效期及 RoleChannel token_roles。旧本机secret不进入产品登录入口。退出沿用 boss.auth.logout 撤销当前身份token。错误请求记录状态与操作，不记录headers。仅同源桌面允许读取这些headers；不加入CORS允许项。

桌面图标严格依据首页和登录页的boss-logo-from-reference.png制作同款高清版本，master为1332×1181透明PNG，导出16—1024像素ICNS。桌面Dock与安装配置使用该高清资源；登录与首页继续引用原始Logo。

独立桌面通过正式App、ClientProvider、NanobotClient及BossDesktop进入首页，读取本目录独立SQLite的现有获准SIMULATED资料。保持老板与维护接口隔离。原有预览、新查看窗口与验证分别使用独立业务数据库、profile、构建目录和动态端口。新查看窗口只读复制本目录既有账号摘要，验证两种真实身份后显示登录页面。原生200%检查使用webContents.setZoomFactor(2)，三个窗口尺寸对应720×512、640×400、512×384内容视口。公共接入由W3负责，完整Runtime、原生安装和页面视觉验收分别记录，未运行内容不得登记通过。
