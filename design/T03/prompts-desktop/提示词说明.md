## 2. 统一生成方式

压缩包中的每份 `.txt` 都是可直接复制的完整提示词，已经包含本节全局规则、对应来源字段、页面布局和状态要求。`desktop/`、`desktop-compact/` 分别保存电脑标准窗口及紧凑窗口主画面；`states/` 保存 51 个主区域及用途视图的 11 种状态与两种电脑窗口变体。21 个补充视图按各自指定用途生成，不机械套用相冲突的状态。144 份主画面与 1122 份状态文本共 1266 份；当前没有手机或平板专属设计交付。

图片生成时一次提交一份提示词，输出一张完整页面。相同项目后续生成时，可同时提供已经认可的页面作为风格参考，并说明仅继承颜色、字体、导航、圆角与组件外观，业务内容按当前提示词执行。当前没有可提供的既有设计图片。

### G01 全局规则

```text
制作广东海大集团 HAID 场景的 Boss Agent 电脑桌面应用高保真界面设计图。画面表达专业、清楚、可信、克制的农业科技企业办公体验。整套应用使用同一设计系统，所有页面保持一致的导航位置、标题层级、字体、卡片、输入框、按钮、表格、来源标签、状态和浮层外观。老板端与管理端均为桌面窗口内的入口；窗口控件遵循目标系统约定，不添加浏览器地址栏或手机导航。系统版本与具体桌面框架尚待验证，不绘制代表已经兼容所有系统的标识。

固定配色：主蓝 #005BAC，深蓝 #073B70，辅助绿 #5CA63B，蓝色浅背景 #EEF5FC，绿色浅背景 #F0F7EB，应用背景 #F5F7FA，容器白色 #FFFFFF，主要文字 #172B4D，次要文字 #52647A，边界 #DCE4ED，成功文字 #237443，提醒文字 #A45A00，错误文字 #B42318。颜色数值属于统一 UI 建议。白色与中性背景构成大部分面积，蓝色用于主操作，绿色仅小面积辅助；状态同时使用文字，颜色含义始终一致。

品牌区使用清晰文字“海大集团 · Boss Agent”。只有提供官方 Logo 源文件时才按原样置入，禁止凭空重画商标。主体是可工作的产品页面，平面正视，无设备外壳、透视效果、场景摄影、人物、海报式大标题或与任务无关的装饰。单张图片只展示当前视图，禁止拼成多页面展示板。

中文采用清晰的现代无衬线字形；页面标题24px/32px、区域标题20px/28px、卡片标题16px/24px、正文16px/24px、说明14px/22px。8px间距基线，允许4px内部间距；卡片内边距24px；输入与按钮高度至少44px；输入圆角4px、卡片8px、弹窗12px；边界1px，浮层有轻度阴影。图标使用同一套功能性线条图标、统一20px视盒与2px线条，不用Emoji代替功能控件。

控件标签使用完整、清晰中文，English标识符保留原名。准确呈现关键字段、对象、来源、版本、时间、当前状态和操作。长标题换行，较长表格明确滚动区域，底部操作不遮盖正文。不增加未经需求支持的部门账号、部门Agent或专业业务操作。

不编造具体金额、数量、客户姓名、人物头像、业务结果、运行ID、性能成绩或费用；需要具体资料而未提供时，使用“待提供”“尚未读取资料”“待核查”“未知”等可读内容，不填零、不造走势图。数值区域保留字段、单位和期间；图表缺少数据时显示明确的无数据状态。目标状态仅是界面状态的设计表达，不作为真实业务已经执行的证明。

事实区分SIMULATED、PUBLIC_SOURCE、RUNTIME_RECORD；每项来源保留作者、版本、时间、范围及原文入口。业务时间与真实运行时间分开。未知保持未知。老板有效授权对应对象、动作、正文或金额、时间、范围与版本；已有有效指令直接执行，缺少或改变的决定性条件才需要本人补充。

交办进展、结果提交、老板确认完成分别展示；发送、送达和回复分别展示；专业判断保留作者及确认程度。取消只停止尚未执行的步骤，已执行结果仍可查询。后台只能技术维护和处理获准模拟资料，老板决定及个人内容修改在老板入口完成，后台不提供代为批准或确认完成按钮。

完整展示产品内容与可操作区域，保持可读字号和明确层级。不要加入“全部已完成”“全部通过”等没有实际证据的宣传式结果。不要输出代码、说明海报或新业务功能。
```

### S03 运行中

```text
将当前画面设为“运行中”。只展示可观察步骤、已执行与尚未执行区域、开始时间字段和可取消范围；实际记录未提供时不造run_id、耗时或百分比。运行中按钮状态清楚，提供取消未执行步骤及查询进展，不提前展示业务成功，不输出模型内部推理。
```

### S04 待输入

```text
将当前画面设为“等待必要输入”。保留当前内容，只突出当前动作缺少的对象、材料、时间、版本或本人决定等必要条件。输入有帮助文字与字段错误，已提供信息不重复索取。提供补充条件和取消未执行步骤，禁止默认自动批准或填写未经提供的值。
```

### S05 本次操作完成

```text
将当前画面设为“本次操作结果”。使用清楚结果卡与可访问的对象、内容版本、处理时间、来源和结果入口字段，未提供的具体值仍为待提供。仅表现结果状态的设计样式，不编造正式记录。查询结束不结束交办，保存配置不表示已经启用和采用，运行成功不表示老板确认完成；任务完成只能依据本人当前决定单独显示。
```

### S06 失败

```text
将当前画面设为“当前操作失败”。错误在对应步骤持续显示，分别保留已执行和未执行项，提供原本允许的补充、查询现状、取消或获准新尝试。未提供原始错误时使用“失败原因待查询”，不伪造异常日志。不自动切换模型、不预填成功结果、不把已有成果删除，不仅使用短暂Toast表达失败。
```

### S07 无权限

```text
将当前区域设为“无法访问此内容”。只保留当前合法导航、身份、说明与返回入口，受限正文、标题、附件、录音、摘要和数值全部不呈现。写入、发送、审批和完成操作不可用并有原因文字。读操作也检查权限，不能仅隐藏按钮；当前画面不展示技术维护代替老板决定的入口。
```

### S08 部分资料与需要复核

```text
将当前画面设为“部分资料尚未更新，需要复核”。清楚列出当前有效范围、缺少范围、截至时间、来源版本、冲突或失效原因。有效内容与受影响内容分别呈现，提供查看历史和读取当前版本。保持原始观察时间，不以刷新时间覆盖，不把缺少数据计零，不声称完整覆盖。
```

### S09 执行结果核查中

```text
将当前画面设为RECONCILING“正在核查执行结果”。区分已知结果、待核查项及尚未执行项，保留原意图和获准运行记录入口。主操作为查询执行结果，同一意图的重复发送与写入暂不可用；取消只作用于尚未执行步骤。只读页面对应查询中断后的结果核查，不能新增写入动作。
```

### S10 已取消与历史只读

```text
将当前画面设为“已取消”或原对象适用的“历史只读”，准确说明取消的操作范围，历史结果及已执行动作保持可读。提供返回和获准的新建关联工作入口，不恢复催办或重新执行。只读页面表示查询已取消或历史版本，不增加业务取消权限；旧执行空间不能向当前空间提交。
```

## 9. 用户执行图片生成时的检查

逐张检查标题、Logo 来源、蓝绿配色、字体、导航顺序、主要字段、对象、来源、权限、取消与结果入口。宽视口与窄视口保持内容相同，核查是否隐藏了金额币种、原文来源、授权范围和必要动作。图像模型产生的中文、状态或数字错误需要在交付前更正。

图片输出不等于可编辑设计源文件、真实业务执行、API 复用、正式可访问性检查或完整素材包。官方 Logo 与标准图标采用已有合法源文件；页面截图不能替代独立素材导出。当前 T02 上游绑定继续等待证据，这不妨碍本次完整提示词交付。
