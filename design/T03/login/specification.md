## 布局与资源

未认证页面包含顶部Logo、中央双区域卡片、品牌欢迎区、凭据表单和认证帮助。品牌区使用现有大鹏正面素材，保留完整比例与自然尺寸，绿色线条强调品牌；表单为白色卡片，主标题使用deepBlue，主要操作使用actionBlue。未认证页面没有业务导航、私人正文、用户资料和经营数值。

实际认证为本机访问凭据，复用`fetchBootstrap`、NanobotClient和RoleChannel。老板与维护入口为radiogroup；所选入口用于核查返回角色，不能产生角色。没有扫码、SSO、注册或企业账号声明。访问凭据不进入URL、日志或设计证据。

Token引用`Boss-Agent-Desktop-Complete-v6/design-tokens.json`：brandBlue #005BAC、brandGreen #5CA63B、actionBlue #0968EA；正文16/24、说明14/22、8px间距、卡片14px圆角、输入9px圆角、2px焦点、至少44px控件。继承当前字体与成功/错误语义。1440×1024、1280×800使用双区域；1024×768与200%缩放允许卡片纵向排列和页面滚动，避免表单或帮助内容被遮挡。减少动态设置下不播放连续动效。

复用资源：`assets/boss-logo-from-reference.png`与`assets/dapeng-front.png`，公开构建路径`/boss-brand/`；来源与许可说明引用v6素材清单。没有新增图片、裁切、生成或视觉检查。

## 状态与行为

| 状态 | 反馈与操作 | 安全与焦点 |
|---|---|---|
| 初始 | 欢迎标题、两类入口、凭据输入与继续认证 | 输入有可见标签，不展示业务内容 |
| 输入 | 密码默认隐藏，可按按钮显示 | 不自动提交，IME期间Enter不提交 |
| 校验错误 | 显示请输入访问凭据 | aria-invalid与错误说明关联，聚焦输入 |
| 认证中 | 明确正在核验身份，按钮与入口禁用 | 同步提交锁防止重复请求 |
| 认证失败 | 凭据无效或已失效，允许重新输入 | 安全错误信息，不复述凭据 |
| 服务不可达 | 显示连接失败与重新尝试 | 不保存成功标记，不显示业务内容 |
| 成功 | 服务端identity与所选入口一致后进入Shell | token与角色绑定，按照当前角色恢复获准页面 |
| 身份范围不符 | 提示凭据身份与入口不符，允许更换入口 | 不建立已认证业务客户端 |
| 登录过期 | D08说明会话已失效、已有结果可认证后查询 | 立即卸载受保护页面及客户端 |
| 重新认证 | 输入当前有效凭据 | 新客户端不自动重发旧业务写入 |
| 主动退出 | 返回N01 | 服务端撤销当前会话token，本地清除秘密及连接 |
| 图片失败 | 显示品牌资源加载失败 | 不采用替代图片，保留文本反馈 |

Tab顺序为入口、凭据、显示密码、提交、帮助。Enter提交与点击共用过程，错误使用role=alert，认证状态使用role=status和aria-live，加载使用aria-busy。帮助解释凭据来源、身份边界与网络条件；不展示凭据文件正文。D08提供重新认证和返回登录；二者均不重放业务动作。

## 独立验收

真实BOSS与MAINTAINER凭据分别进入获准Shell；联系人identifier与错误凭据401、越权403。实际当前会话退出后，原API token不能再访问受保护读取。重复点击与键盘操作只产生一个有效bootstrap。服务进程停止时显示不可达，恢复后可重新认证。过期与重新认证不增加业务发件箱记录。三个视口和200%缩放验证DOM、焦点、标签、滚动与错误。所有步骤使用真实服务，禁止替代响应；没有真实触发的状态保持NOT_RUN。视觉与像素检查NOT_RUN。
